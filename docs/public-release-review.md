# 공개 전 점검 상태

## 최신 수정 상태

2026-10-15 갱신. [최종 산출물·검증 결과](public-release-remediation-result-20261014.md)를 현재 판정의 기준으로 삼는다. 현재 소스만 담은 새 Git 저장소와 고지·대응 소스·체크섬을 갖춘 Windows `v0.2.0-preview.2`를 등록하고 검증했다. 기존 개발 이력의 GitHub 저장소는 사용자의 후속 요청으로 삭제했으며 검증된 로컬 복구 백업만 보관한다. [저장소 이력 안내](repository-history.md)를 참고한다. 현재 소스와 고정된 Windows 시험 배포만 공개하는 범위에서, 확인된 미해결 라이선스·고지·대응 소스 또는 개인정보·자격 증명 차단 항목은 발견되지 않았다. 라이선스 원문·고지와 고정 태그·대응 소스 ZIP을 함께 유지하는 조건으로 공개 가능하다고 판단한다. 사용자의 공개 요청에 따라 2026-10-15에 현재 소스와 Windows `preview.2`를 공개했다. 과거 감사 기록·고정 배포 태그·파일은 검증 당시 내용을 유지한다.

아래의 공개 보류 판단과 미완료 체크박스는 **수정 전 소스·preview.1에 대한 2026-10-14 감사 기록**이다. 현재 preview.2의 미해결 항목으로 해석하지 않는다. 각 지적의 조치와 검증 범위는 [수정 내역](public-release-remediation-20261014.md) 및 위 최종 산출물에서 확인한다. macOS/Arch의 실기기 수락·배포 패키지, 코드 서명·설치·자동 업데이트는 Windows 시험 배포와 구분하는 후속 범위다.

## 이전 감사 기록 — 2026-10-14

2026-10-14. 현재 단계는 `froiibn/ARTEX-Desktop`의 비공개 개발·검토다. 소유자가 다운로드할 수 있도록 Windows 개발 시험 빌드 `v0.2.0-preview.1`을 비공개 Releases에 제공한다. **공개 전환과 외부 바이너리 배포의 라이선스 검토는 완료되지 않았다.** 원본 전체 저장소·사용자 작업 공간·OS API 키 저장소는 업로드하지 않는다.

일반 README와 실행 안내의 출처 고지는 [ARTEX 원작자·수정 사항](../ARTEX_NOTICE.md)을 중심으로 표시한다. 의존성 수·목록은 일반 안내에서 제외하고, 필요한 라이선스 원문과 [상세 고지](licenses/third-party-notices.md)는 별도 자료로 보존한다. 이 표시 방식의 변경은 배포 조건 점검을 대신하지 않는다.

전수 목록·출처·고지 점검 결과는 [2026-10-14 라이선스 감사](license-audit-20261014.md)에 정리했다. 현재 판정은 공개 보류다. 전체 선언 확인과 공개 배포 조건 충족을 구분한다.

후속 [미사용 코드 정리](unused-code-cleanup.md)에서 이전 Tauri/React와 별도 엔진 구현을 현재 작업 트리에서 제거했다. 아래 839개는 정리 전 고정 감사 수치이며 현재 수는 정리 기록을 따른다. 과거 Git 기록과 기존 Releases는 별도로 남아 있으므로 작업 트리 정리만으로 공개 조건이 모두 해소되지는 않는다.

## 최종 검토 갱신

[2026-10-14 최종 검토](public-release-final-review-20261014.md)에서 최신 소스의 새 clone Windows 빌드·통합 자체 시험, 전체 Git 이력의 인증정보 패턴·후보 문맥, 기존 릴리스 해시와 대응 소스 파일을 재확인했다. 새 clone 빌드·자체 시험은 통과했으며, 앱 내 원작자·AGPL 안내와 기존 배포 파일의 고지 누락이 남아 있어 현재 소스와 기존 릴리스를 그대로 함께 공개하는 것은 보류를 권고한다. 현재 저장소는 비공개다.
