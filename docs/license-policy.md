# 원본 ARTEX의 추가 사용 제한 처리 방침

2026-10-14 · 한국어 / English / 简体中文

## 한국어

ARTEX Desktop은 원본 ARTEX를 바탕으로 만든 수정 버전이며, 프로젝트 전체의 **AGPL-3.0-only**와 [LICENSE](../LICENSE) 원문을 유지한다. 이 문서는 라이선스 원문을 바꾸는 문서가 아니라, 원본 README의 별도 사용 금지 문구를 이 수정 버전에 어떻게 적용하는지 기록한 처리 방침이다.

원본 README에는 로컬 격리 환경에서의 학습·소스 연구·기술 검증만 허용하고, 온라인 서비스·연결된 시스템에 대한 검사·탐색·모의침투와 실무 사용을 자기 소유 또는 승인받은 자산에서도 금지하는 별도 문구가 있다. ARTEX Desktop은 이 용도 제한을 **파생 프로젝트의 추가 라이선스 조건으로 채택하지 않는다**. 원본 README와 이전 점검 기록은 출처·검토 이력으로 보존하며, 그 문구를 이 앱의 EULA나 배포 조건으로 다시 부과하지 않는다.

이 처리는 AGPL 제7조와 제10조에 근거한다. 제7조는 허용된 추가 조항과 그 밖의 추가 제한을 구분하고, AGPL과 함께 고지된 추가 제한을 제거할 수 있게 한다. 제10조는 AGPL이 부여하거나 확인한 권리에 추가 제한을 부과하는 것을 허용하지 않는다. 이 프로젝트는 위 온라인·용도별 사용 금지를 해당 추가 제한으로 처리한다. [GNU 공식 AGPL v3 원문 제7·10조](https://www.gnu.org/licenses/agpl-3.0.html), [동일 원문의 SPDX 확인본](https://spdx.org/licenses/AGPL-3.0-only.html).

다음 의무와 고지는 유지한다.

- 원작자 **Autumn-27**과 기여자의 저작권·출처 고지, 수정 버전임을 밝히는 표시와 수정 날짜
- AGPL이 요구하는 라이선스 고지, 수정·재배포 조건과 바이너리에 대응하는 소스 제공, 적용되는 경우의 네트워크 사용자 소스 제공 의무
- 적용 법률의 범위에서 무보증·책임 제한 고지와 원작자의 공식 배포·보증·제휴를 오인시키지 않는 설명
- 실제 적용 법률, 대상 접근·검사 권한, 개인정보·서비스 조건 및 실제로 체결하거나 수락한 별도 계약에 따른 의무

방어적 보안 점검과 사용자가 소유하거나 테스트 권한을 받은 대상의 검증은 이 프로젝트가 지향하는 목적이다. 이 목적 설명을 AGPL 권리를 제한하는 새로운 용도별 라이선스 조항으로 만들지 않는다. 소프트웨어의 저작권 라이선스는 다른 사람의 시스템에 접근하거나 검사할 권한을 대신 부여하지 않는다.

확인한 원본과 재구축 저장소의 소스·문서에서는 위 사용 금지를 개별적으로 합의한 별도 계약 문서를 발견하지 못했다. 이는 저장소 밖에서 체결된 계약, 별도로 수락한 서비스 조건이나 모든 실제 계약이 없다는 단정이 아니다. 이 방침은 그러한 계약의 존재·효력이나 특정 지역 법률상 원본 고지의 효과를 판정하지 않는다. 실제 계약과 AGPL 의무가 충돌하면 AGPL 제12조를 포함한 관련 조건을 검토해야 한다.

원작자의 추가 허락이 모든 AGPL 사용·수정·재배포에 무조건 필요하다고 설명하지 않으며, 모든 법적 분쟁이나 제3자 권리가 해결되었다고 보증하지 않는다. 현재 저장소는 비공개이며 Windows `v0.2.0-preview.2`와 대응 소스를 비공개 Releases에서 제공한다. 패키지의 고지·소스·검증 범위는 [최종 산출물 기록](public-release-remediation-result-20261014.md)을 따른다. 공개 전환은 수행하지 않았다. 이전 감사 문서는 당시 상태를 보여 주는 역사적 증거로 유지한다.
